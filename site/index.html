Ditto records what you do in the browser and turns it into a step-by-step guide with annotated screenshots. Record, edit, then replay or export.

Install Ditto View on GitHub

What it does

Auto-capture

Every click, keystroke and navigation becomes a step with its own annotated screenshot.

Smart blur

Emails, cards, IDs and IP addresses masked before the screenshot is taken. Pick any other element by hand.

Guide Me

Replay a guide live on the real page, highlighting each next element as you go.

Export anywhere

PDF, DOCX, HTML, Markdown, video or GIF — all generated in the browser.

Getting it

On Edge, install it from Microsoft Edge Add-ons. The Chrome and Firefox listings are still in review; until they're published you can load it manually — about a minute, and it's the same build that was submitted.

Local-first, genuinely

No backend, no account, no telemetry. Guides and screenshots stay in your browser's own storage. The optional AI and voice features use a provider you choose with your own key — or a model server you run yourself, in which case nothing leaves your machine at all.
